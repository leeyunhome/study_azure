# study_azure

Microsoft Azure Fundamentals(AZ-900) 학습 저장소입니다. 목표는 자격증 취득이 아니라 Azure 기초 이해입니다.

- 참고: [AZ-900 자격증 페이지](https://learn.microsoft.com/ko-kr/credentials/certifications/azure-fundamentals/)
- 기준: 공식 스터디 가이드 (2026-07-20 기준 측정 기술)

## 로드맵

**영역 1. 클라우드 개념 (25~30%)**
1. 클라우드 컴퓨팅
2. 클라우드의 이점
3. 클라우드 서비스 유형 (IaaS/PaaS/SaaS)

**영역 2. Azure 아키텍처 및 서비스 (35~40%)**
4. 핵심 아키텍처 구성 요소
5. 컴퓨팅·네트워킹
6. 스토리지
7. ID·액세스·보안

**영역 3. Azure 관리 및 거버넌스 (30~35%)**
8. 비용 관리
9. 거버넌스·규정 준수
10. 관리·배포 도구
11. 모니터링
